# ⚡ Calculadora de Consumo de energia

## 📌 Objetivo
Este projeto calcula o consumo mensal de energia elétrica de um aparelho, com base na sua potência e no tempo de uso diário.

## 🐍 Linguagem utilizada
- Python

## 🧮 Fórmula utilizada
Consumo mensal (kWh):
(potência × horas por dia × 30) ÷ 1000

## 💡 Funcionalidades
- Inserir nome do aparelho
- Informar potência (W)
- Informar tempo de uso diário
- Calcular consumo mensal
- Calcular custo estimado

## ▶️ Como executar
1. Abra o terminal
2. Navegue até a pasta do projeto
3. Execute o comando:

python app.py

## 💰 Cálculo de custo
Foi utilizado o valor de:
R$ 0,75 por kWh
